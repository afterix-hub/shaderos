# Security Policy

## Supported Versions

Security fixes are made against the latest released version of ShaderOS (currently `1.0.0`). Older versions are not patched separately.

## Reporting a Vulnerability

If you believe you've found a security vulnerability in ShaderOS, please report it privately rather than opening a public GitHub issue.

Email **support.toolsstudio@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it, including your Unity version and ShaderOS version
- Any proof-of-concept code, if applicable

You should expect an initial response within a few business days. Once a report is confirmed, a fix is prioritized and a new version is released; we'll credit you in the release notes unless you'd prefer otherwise.

Please don't publicly disclose a suspected vulnerability until a fix has shipped.
