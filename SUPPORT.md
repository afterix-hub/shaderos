## Reporting a bug

Before filing, check the [documentation repository's Troubleshooting page](https://github.com/tools-studio/shaderos-docs/blob/main/docs/troubleshooting.md) to see if the issue is known.

When reporting, include:
- Unity version and render pipeline
- ShaderOS version
- Steps to reproduce
- Console output (if any)

File a product bug via the [Bug Reports channel][bugs]. A bug in this repository's source itself — a compile error, a broken build, a source-level defect — can also be filed as a [GitHub Issue](https://github.com/afterix-hub/shaderos/issues).
