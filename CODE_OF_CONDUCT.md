# Code of Conduct

## Our Standard

This repository exists so that ShaderOS's customers and the wider Unity community can read, learn from, and contribute to its source. Participating — through an issue, a pull request, a discussion, or any other channel tied to this project — means holding to a simple standard: be respectful, and assume good faith.

Examples of behavior that helps:

- Giving and accepting constructive feedback gracefully
- Focusing on what's best for the project and its users
- Being patient with contributors who are still learning the codebase

Examples of behavior that isn't acceptable:

- Harassment, insults, or personal attacks, public or private
- Publishing others' private information without consent
- Sustained disruption of issues, pull requests, or other project discussion

## Scope

This applies within all spaces tied to this project — issues, pull requests, discussions — and in any other setting where someone is representing the project or its community.

## Enforcement

Violations can be reported privately to **support.toolsstudio@gmail.com**. Reports are reviewed and handled as discreetly as possible. Anyone asked to stop unacceptable behavior is expected to comply; maintainers may remove comments, close issues or pull requests, or block a contributor whose behavior violates this code.
